# /short-video-script — 全行业通用短视频脚本生成器

触发词："做一条 [X]" / "写这个主题的脚本" / "给我出文案" / "脚本"

## Phase 0：用户配置加载（每次运行必须先执行）

**执行步骤：**

1. 尝试读取文件 `~/.claude/skills/short-video-script/profile.md`
2. **如果文件存在** → 加载配置，进入 Phase 1 正常执行
3. **如果文件不存在** → 进入「首次使用 · 人设配置向导」，完成后保存配置，再继续执行

---

### 首次使用 · 人设配置向导

> 你好！这是你第一次使用 /short-video-script。
> 我需要了解你的基本信息，才能生成贴合你行业和人设的脚本。
> 请依次回答以下问题，全部回答后我会帮你保存配置，以后直接使用。

按顺序逐条提问，等待用户回答后再问下一条：

**[Q1] 你的行业 / 领域是什么？**
> 例：化妆品包材、家居装修、宠物用品、教育培训、法律咨询、健康食品…

**[Q2] 你的产品 / 服务具体是什么？**
> 例：玻璃瓶、喷涂工艺、代加工服务 / 儿童英语课程 / 宠物营养品…

**[Q3] 你有几个内容人设？分别叫什么名字？**
> 例：只有一个 → "张总"；两个 → "慧姐" 和 "阿明"

**[Q4] 针对每个人设，分别填写：**
> - 从业年限
> - 核心差异化竞争力（你跟同行最不一样的地方是什么）
> - 你有哪些资源/工厂/团队背书（可选）

**[Q5] 你的目标客户是谁？（可以列出 2-4 类）**
> 例：品牌采购经理 / 小品牌老板 / 产品经理 / 个人创业者…

**[Q6] 你的客户最核心的恐惧/痛点是什么？**
> 即：他们找你之前最担心发生什么事？最怕被谁坑？
> 例：找错供应商导致货期延误、产品品质将就、钱花了效果落不了地

**[Q7] 你所在行业，客户有哪些「错误认知/隐含假设」？**
> 例：以为报价差不多选便宜的就行 / 以为签了合同货期就有保障
> 可以先列 2-3 条，后续随时补充

**[Q8] 你帮客户解决的核心问题是什么？一句话说清。**
> 例：让客户的包装想法按预期落地 / 让孩子的英语从0开始真正开口说

**[Q9] 你的业务里有哪些专业知识点或产品细节可以展示给客户？**
> 例：工艺类型、材质对比、行业潜规则、常见踩坑点…
> 这些会用于出题时增加专业背书，列几条关键的即可

**[Q10] 你有几个人设？这条视频优先使用哪个？（或两版都出）**

收集完成后，按以下格式保存到 `~/.claude/skills/short-video-script/profile.md`：

```markdown
# 用户配置文件

## 基本信息

- **产品/服务**：[Q2答案]

## 人设信息

### [人设A名称]

- 核心差异化：[答案]
- 背书资源：[答案]

### [人设B名称]（如有）
- 从业年限：[答案]
- 核心差异化：[答案]
- 背书资源：[答案]

## 目标客户
[Q5答案列表]

## 行业第一性原理
**核心洞察（一句话锚点）**：[基于Q6提炼，格式：找错XX，你的XX就会出问题]

**客户真实恐惧**：[Q6答案]

## 客户隐含假设（待打破）

| 客户的错误认知 | 用内容打破它 |
|-------------|-----------|
| [Q7条目1] | [提炼打破方向] |
| [Q7条目2] | [提炼打破方向] |

> 持续迭代：根据视频反馈补充新的隐含假设。

## 核心价值主张
[Q8答案]

## 行业专业知识点
[Q9答案，整理成列表]

## 文案完成后自查
每条文案写完，问自己：**看完这条视频的客户，有没有感受到"[Q6核心恐惧]"这件事？**
```

## 一、8大爆款元素

> **用法说明：** 爆款元素不只是开场钩子，而是贯穿整个文案的底层逻辑。开头可以用来抓注意力，中间用来维持情绪张力，结尾用来强化记忆点。写文案时随时问自己：这里能不能加一个爆款元素进来？

### 1. 成本的
- 便宜又有面子的
- 十分之一的时间/金钱
- 花大钱干的
- xx如何贪小便宜

### 2. 人群的
- 想要（）但不具备条件的
- 因为（）导致现在可愁了

### 3. 奇葩的
- 外行人不知道的
- 黑心内幕操作
- 脑回路有病的

### 4. 头牌的
- 明星/名人/名校/名企
- 电视剧里出现的
- 生意最好的

### 5. 怀旧的
- 古代/具体朝代的
- 20年前的
- 历史风潮盘点

### 6. 反差的
- 身份反差
- 南北/品牌/穷富

### 7. 最差的
- 最没面子的/样子最丑的
- 最好吃
- 差评最多/贬值最多

### 8. 荷尔蒙的
- 带帅哥/美女出镜，用颜值吸引注意力
- 帅哥/美女来找我咨询/挑产品，自然引出产品介绍
- 例：今天有个开保时捷的美女来找我选产品，她让我推荐几款新款，顺势带出产品，最后现场挑选呈现

## 二、文案结构总原则

**爆点前置 → 信息密度 → 金句收尾**

> **注意：** 爆款元素不是只在开头加，整个文案过程中都可以融入。开头用来破冰抓人，中段用来维持情绪不掉，结尾用来留钩子或制造共鸣。好的文案是从头到尾都有张力，不是只有开头一句猛的。

## 三、选题方向 + 出题&文案模版

> **执行说明：** 以下4大方向的模版中，凡出现「[人设A]」「[人设B]」「[行业/领域]」「[产品/服务]」「[客户痛点场景]」「[专业知识点]」等标记，均从 **Phase 0 加载的用户配置** 中取值替换后再输出。
>
> 模版的**结构、问法、格式一字不改**；替换的只是括号内的业务变量。

整体分四大类：
- **教知识类**（方向一～四）：解决难题 / 案例引入 / 推荐建议 / 揭秘避坑
- **讲故事类**：小有成就 / 成功案例 / 平凡英雄 / 苦难经历
- **聊观点类**：我要站台 / 我要批判
- **晒过程类**：过程展示 / 测评产品 / 任务挑战 / 事件体验

## 讲故事类

**核心：** 案例、自己

**4个分支：** 小有成就 / 成功案例 / 平凡英雄 / 苦难经历

**出题逻辑：** 故事的重点是让客户通过你的故事产生信任。可以是自己的经历，也可以是客户的经历。关键是故事要有具体的细节、有情绪起伏、有转折、有结果。

**文案结构：** 故事重点 → 原因 → 过程 → 结果 → 分析 → 总结

---

## 聊观点类

**核心：** 同类、支持

**2个分支：** 我要站台 / 我要批判

**出题逻辑：** 输出判断、站队、表态。核心是观点够狠、立场够清、让人听完想站队。

**文案结构（滑梯理论）：** 爆点前置（第一句就是观点）→ 信息密度（最短时间给最多信息）→ 金句收尾（短、狠、有立场）

## 五、执行流程

### Phase 0（每次必做）：加载用户配置

1. 读取 `~/.claude/skills/short-video-script/profile.md`
2. 如不存在 → 进入首次配置向导
3. 如存在 → 加载所有变量（人设名称、行业、产品/服务、目标客户、核心痛点、隐含假设等）
4. 特殊指令：如用户输入「更新配置」/ 「修改人设」/ 「reset」→ 重新进入配置向导，覆盖保存

### Phase 1：解析用户输入

读取：
- 人设选择（[人设A] / [人设B] / 默认两版都出）
- 大类（教知识 / 讲故事 / 聊观点 / 晒过程）
- 子方向（教知识→解决难题/案例引入/推荐建议/揭秘避坑；讲故事→小有成就/成功案例/平凡英雄/苦难经历；聊观点→我要站台/我要批判；晒过程→过程展示/测评产品/任务挑战/事件体验）
- 具体话题

### Phase 2：匹配爆款元素

根据话题，从8大爆款元素中选1-2个融入选题或开场钩子。

### Phase 3：生成脚本

按选题方向对应的文案结构生成，将模版中的 `[人设A]`、`[人设B]`、`[行业/领域]`、`[产品/服务]`、`[目标客户]`、`[客户痛点场景]` 等变量全部替换为 Profile 中对应的值，严格遵守：
- 爆点前置 → 信息密度 → 金句收尾
- 字数控制300-400字
- 大白话，不要专业感强的词语
- 只出纯文案（晒过程方向），或出完整脚本（其他方向）

### Phase 4：质检

- ✅ 开篇有钩子/爆点吗？
- ✅ 文案结构对应选题方向吗？
- ✅ 字数在300-400字范围内？
- ✅ 语言通俗易懂，没有过度专业词？
- ✅ 结尾有金句/行动启发？
- ✅ 两版人设（如需）语气差异明显？
- ✅ 所有变量已替换为用户实际业务信息？
